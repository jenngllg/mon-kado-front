# Extension MonKado pour Chrome — bêta 1.1.0

Cette extension utilise votre compte sur [www.monkado.fr](https://www.monkado.fr/). Aucun serveur local n’est nécessaire.

## Première installation

1. Décompressez toute l’archive dans un dossier que vous conserverez sur votre ordinateur.
2. Dans Chrome, ouvrez `chrome://extensions` et activez le **Mode développeur**.
3. Cliquez sur **Charger l’extension non empaquetée**, puis choisissez le dossier contenant `manifest.json`.
4. Connectez-vous à MonKado, actualisez l’onglet et laissez-le ouvert.
5. Sur une page produit, ouvrez l’extension **MonKado — ajouter un souhait**. Vérifiez le nom, le prix et l’image, cochez les listes souhaitées, puis cliquez sur **Ajouter**.

## Mise à jour d’une version déjà installée

1. Fermez la fenêtre de l’extension, puis remplacez les fichiers de son dossier par le contenu de cette archive.
2. Dans `chrome://extensions`, cliquez sur **Actualiser** pour MonKado et vérifiez la version **1.1.0**.
3. Actualisez votre onglet MonKado, puis rouvrez l’extension depuis une page produit.

Conservez le dossier extrait : Chrome l’utilise pour charger l’extension. Avec plusieurs listes, les cases à cocher sont visibles dès l’ouverture ; « Listes * » reste en gras, sans encart autour du titre. La première liste est cochée initialement. Le prix Amazon privilégie le total de l’article et écarte les mensualités détectables. Le nom, le prix et la photo restent à vérifier avant l’ajout.

L’extension utilise la session de l’onglet MonKado sans conserver votre mot de passe. Après un ajout dont le résultat n’a pas pu être confirmé, vérifiez vos listes avant de réessayer.

## Proposer une idée surprise

1. Depuis une page produit, ouvrez l’extension et choisissez **Idée surprise**.
2. Dans **Pour qui ?**, choisissez une personne présente dans vos groupes.
3. Cochez les listes souhaitées. Le groupe est indiqué à côté de chaque liste ; une même liste partagée dans deux groupes constitue deux destinations privées distinctes.
4. Vérifiez le nom, le prix et la photo, puis cliquez sur **Proposer l’idée**.

Les idées sont visibles par les membres des groupes indiqués, sauf leur bénéficiaire. Aucun formulaire MonKado ne doit être ouvert au préalable. Après un refus partiel, **Réessayer les listes restantes** conserve les ajouts déjà confirmés.

Ce parcours nécessite le site et l’API compatibles avec la version 1.1.0. Si l’extension demande d’actualiser MonKado et que le message persiste, cette mise à jour du site n’est pas encore publiée. Les souhaits personnels restent utilisables avec le site compatible précédent.

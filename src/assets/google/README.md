# Google sign-in assets

These assets are served locally and used only for the Google sign-in action.

- `g-logo.png`: unmodified official gradient G, downloaded from https://developers.google.com/static/identity/images/g-logo.png.
- `google-sans-medium.ttf`: official Google Fonts subset (weight 500, text `Continuer avec Google`), downloaded through https://fonts.googleapis.com/css2?family=Google+Sans:wght@500&display=swap&text=Continuer%20avec%20Google.
- The font's embedded copyright is Copyright 2025 The Google Sans Project Authors (github.com/googlefonts/googlesans). Its SIL Open Font License 1.1 is reproduced in `OFL.txt`.

The Google logo remains subject to Google's brand rules, not the font license: https://developers.google.com/identity/branding-guidelines. Do not recolor or distort it. MonKado's remaining interface continues to use Nunito Sans.

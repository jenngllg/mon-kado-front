## Exécution et limites

- `pnpm test:e2e` : interfaces, états, erreurs et navigation avec réponses API contrôlées.
- `pnpm test:regression` : tous les projets natifs, sur mobile et ordinateur, chacun avec une base jetable. API, worker, images, mails locaux et exports sont réels. Aucun service de production n’est utilisé.
- `pnpm test` et `python -m unittest discover -s tools/native-e2e -p 'test_*.py'` contrôlent la matrice et la sélection des projets dans la CI.
- Les pages légales sont vérifiées par les tests de navigation et les tests unitaires des routes statiques.
- Aucune connexion réelle au fournisseur Google dans la CI.
- Installation et autorisation push simulées dans la suite : réception sur téléphone réel non vérifiée.
- Installation manuelle de l’extension et sites marchands réels non exercés par Playwright.

Les codes TOTP, comptes et boîtes mail des tests sont fictifs. Le calcul cryptographique, les décisions d’autorisation et la persistance sont exécutés par le vrai serveur. Aucun taux de couverture des branches n’est déduit du nombre de scénarios.
